# Datasets Directory (`data/`)

Place datasets in this directory for training and evaluating custom machine learning models.

## Recommended Datasets

### 1. Resume Role Classification & Skill Extraction
- **Kaggle Resume Dataset** (e.g., `UpdatedResumeDataSet.csv` or `Resume.csv`):
  - **Task:** Supervised multiclass text classification (predicting target job domain / role from resume text) or Named Entity Recognition (NER) for skills.
  - **Required Columns:**
    - `Resume` or `Resume_str`: Raw text of the resume.
    - `Category`: Role label (e.g., `Data Science`, `DevOps`, `Web Designing`, `Java Developer`).
  - **Labels for Supervised Learning:** Yes, contains categorical labels for resume role classification.

### 2. Job Description & Keyword Alignment
- **Kaggle Job Descriptions Dataset** (e.g., `job_descriptions.csv`):
  - **Task:** Unsupervised similarity matching, TF-IDF vocabulary building, or weak supervision for skill co-occurrence.
  - **Required Columns:**
    - `Job Description`: Full text of the job description.
    - `Job Title`: Target role name.
    - `Skills` (optional): Comma-separated required skills.
  - **Note on Labels:** Job description datasets typically **do not** contain labeled resume-to-job fit scores (0-100%). Scoring tasks require either human-annotated resume-job pairs or synthetic multi-factor rubrics.
